# 비디오 생성: 무료 API 기반 파이프라인 구축

## 1. 배경
아이디어 텍스트를 영상으로 만들려면 '이미지 생성', 'TTS(음성)', '영상 합성' 기술이 필요함.
시중의 좋은 API들은 대부분 유료인데, 현재 프로젝트 예산으로는 감당이 안 됨.

## 2. 해결 방안
비용이 들지 않으면서도 쓸만한 퀄리티를 내는 오픈소스 및 무료 API들을 찾아서 조합함.

## 3. 사용 기술
| 구분 | 도구 | 선정 이유 |
| :--- | :--- | :--- |
| **이미지** | Pollinations.ai | API 키 없이 무료로 무제한 생성이 가능함. |
| **음성(TTS)** | Edge-TTS | MS 엣지 브라우저의 내장 기능을 활용해 무료로 고품질 한국어 음성을 쓸 수 있음. |
| **합성** | FFmpeg | 영상과 음성을 합치고 자막을 입히는 표준 툴. |

## 4. 향후 계획
지금은 가성비 세팅이지만, 나중에 서비스가 커져서 자금이 생기면 유료 API로 교체할 수 있게 구조는 유연하게 짜둠.
