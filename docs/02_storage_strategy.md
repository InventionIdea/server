# 스토리지 전략: Google Drive에서 Cloudflare R2로 전환

## 1. 배경
생성된 동영상은 용량이 커서 DB에 직접 저장할 수 없음. 초기에는 빠르게 구현하기 위해 Google Drive API를 사용해 파일을 올리고 링크만 DB에 저장하는 방식을 썼음.

## 2. 문제점
- **확장성 한계**: 구글 드라이브는 파일 서버 용도로 만들어진 게 아니라서, 트래픽이 늘어나면 속도 제한이나 차단 문제가 생길 수 있음.
- **표준 미준수**: 추후 AWS S3 같은 전문 스토리지로 넘어갈 때 코드를 전부 뜯어고쳐야 함.

## 3. 결정
**객체 스토리지 서비스인 Cloudflare R2를 도입함.**
- **R2 선정 이유**: AWS S3와 호환되면서도, 데이터 다운로드 비용(Egress fee)이 무료라 동영상 서비스에 유리함.
- 추후 AWS S3로 넘어가더라도 설정만 바꾸면 되도록 설계함.

## 4. 결과
- 파일 업로드/다운로드가 안정됨.
- 특정 벤더(Google) 종속성을 끊고, 표준 객체 스토리지 인터페이스를 확보함.
